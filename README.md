 Vehicles App

Uma aplicação interativa construída com **Streamlit** para explorar e analisar dados de veículos.  
Permite visualizar estatísticas, gráficos dinâmicos e realizar filtros sobre o dataset `vehicles.csv`.

---

## Funcionalidades

- Visualização interativa dos dados
- Gráficos dinâmicos com Plotly
- Estatísticas descritivas (preço médio, quilometragem média, etc.)
- Filtros por preço, ano, condição e outros atributos
- Interface simples e intuitiva
